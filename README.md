# Melody sound-bank API

Generated by `tools/banks/exs-to-bank.mjs` from `tools/banks/banks.json`. Upload this folder as is: the app
resolves every path against the base URL of this folder (`<base>/catalog.json`, `<base>/banks/...`).

## Layout

```
catalog.json                                  every bank: path, files (bytes, sha256), totalBytes; the instrument map
banks/<family>/<bank id>/v<version>/bank.json  zones, choke groups, programs (schema 2, below)
banks/<family>/<bank id>/v<version>/samples/   16-bit PCM WAV, one file per sample
```

Families follow the app's instruments (keyboard, guitar, bass, drums, strings, world, …). A changed bank is
published as a new version folder; files of a published version never change (the app caches by version).
Sample names: `<MIDI key>[-<drum piece>]-v<velocity layer>[-pedal][-<round robin a/b/…>].wav`, release
noises `release-<n>.wav`. Keys are MIDI note numbers (60 = middle C).

## bank.json (schema 2)

- Bank: `id`, `name`, `family`, `version`, `sampleRate` (most files; each WAV carries its own rate and
  channels), `channels` (the most of any file), `gainDb` (applied to every zone), `velocityExponent` (gain =
  (velocity / 127) ^ exponent), `fillUncoveredKeys` (false: keys without a zone are silent).
- `groups[]`: choke groups, `{ name, polyphony }`. A new voice in a group releases the group's oldest voices
  beyond `polyphony` (hi-hats: 1, so the closed hat cuts the open one).
- `programs[]`: `{ id, attackMs, releaseMs, polyphony, oneShot, keymap: [{ from, to }] }`; the keymap maps a
  played key to the key whose zones play (and pitch).
- `zones[]`: `file`, `start`/`end` (frames in the file), `rootKey`, `loKey`/`hiKey`, `loVel`/`hiVel`,
  `fineCents`, `gainDb`, `pan` (−1…1), `pitchTracking` (false: plays at its own pitch on every key),
  `oneShot` (ignores key release), `reverse`, `trigger` (`attack` on key down, `release` on key up at
  release velocity 64), `pedal` (`any`, `up`, `down`: chosen by the sustain pedal at key down), optional
  `loopStart`/`loopEnd` (frames, sustain loop), `roundRobin` `{ set, step, count }` (zones of a set
  alternate hit by hit), `group` (choke group index), `releaseDecayMs` (a release zone fades to silence for
  notes held this long).

Every zone whose key, velocity, pedal state and round-robin step match plays (layers sound together).

## Adding a bank

Add an entry to `tools/banks/banks.json` (family, id, version, EXS sources and sample folders, programs,
verified notes) and run `node tools/banks/exs-to-bank.mjs --only <id>`; upload the new version folder and the
updated `catalog.json`.
